# 前端界面注意事项

- 以现有 Agent 工作区为视觉基准，三个模块保持统一、简洁、紧凑的风格；优先复用公共组件和样式。
- 颜色使用现有主题变量，字体、字号、圆角和间距沿用公共规范；标题与正文层级清楚，不靠缩小字号解决拥挤。
- 浅色和深色都要有清晰的悬浮、选中、禁用及焦点反馈，尤其注意浅色侧栏的悬浮高亮。
- 提示框、下拉选项、菜单和删除确认使用应用内统一样式，避免原生 title、系统确认框与界面混搭。
- 精简重复标题、按钮和说明，避免大面积空白及层层套卡片；保留必要的错误与操作后果提示。
- 长内容优先用弹窗查看或编辑，固定标题与操作区、内部滚动；浮层对齐自然，不越界、不遮挡关键操作。
- 适配窄窗口、大字号和长文本，避免横向溢出、控件挤压；输入工具栏保持单行，代码审查保持左右布局。
- 交互及时、直接且可逆：开关能再次关闭，悬浮预览随当前条目更新；不丢失草稿、未保存编辑或用户设置。
- 修改后实际检查显示与交互，不只看代码；至少确认浅深色、窄布局、悬浮、展开与关闭。
- 只调整用户要求的范围，不擅自增加功能或改变业务流程，不修改 pi-agent 核心。

详细规范按需参考 [主题说明](docs/WORKSPACE_THEME_GUIDE.md) 和 [设计规划](docs/CLIENT_UI_REDESIGN_PLAN.md)，以最新用户要求为准。
