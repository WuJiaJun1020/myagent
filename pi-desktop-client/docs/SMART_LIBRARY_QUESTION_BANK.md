# 智慧图书 · 题库与人工审核

## 使用

打开已导入的《凡人修仙传》，点击阅读工具栏中的 **题库与审核**。按难度或审核状态筛选，在右侧核对题目、参考答案、推理说明和证据。点击 `[序号]` 可查看原文上下文及高亮，并跳转阅读页；此操作不需要运行模型或构建索引。

当前保留200道常驻题（简单100、中等50、困难50），首次使用默认加入评测；已有编辑、备注和审核状态保持原样。**驳回**、**重新待审**、**移出评测**能撤销评测资格。编辑题目、答案、推理或证据支持要点后重新待审，避免旧审核结果继续生效。**通过审核**只批准内容，再点击 **加入评测**后生效。后续新批次仍默认待审核，不能自动继承常驻题的资格。

批量操作作用于当前审核状态、难度、批次和搜索条件筛选出的题目：**批量通过**仅批准内容，**通过并加入评测**一次完成批准和接入。按钮显示实际待处理数量，已完成的题目不重复处理；未保存的编辑或备注须先处理。批量保存保留原有内容与备注，任一题目版本过期或原文校验失败则整批不保存。重新运行召回评测后使用新题集，已经运行的报告保持原快照。

T开头的15道旧样题及首批30道题已停用并移出运行资源。评测只读取现题库中已加入的题目，不再拼接隐藏基线。运行中修改题库不改变当前报告，重新运行后生效。完整题目与证据内容参与报告的 datasetHash。新报告使用 `fanren-resident-v2`；旧报告保留为本地历史，但界面提示重新评测，不能将其245题统计当成当前200题结果。

## 出题规范

- 首批简单、中等、困难各 10 题，分别由 GPT-6 Luna、high 思考程度的子智能体负责。
- 全书按实际物理章节划分十个区间，每种难度各区间一题，使用固定随机种子选择参考事件；支持在同区间调整到更适合出题的实际章节。
- 摘要与补充笔记只用于找线索，最终答案必须由原文支持。区分人物猜测与事实，避免自行补算年龄、重复累加时长和切碎一句来凑证据。
- 证据保存原始 UTF-16 半开区间、原文 SHA-256、物理章、印刷章标题和行号，不依赖当前 RAG 切片。原文件有重复章号，不能直接拿印刷章号推算偏移。
- 校验程序检查精确引文、章节边界、区间分布、证据重叠及难度结构；它不能证明答案正确或证据充分，这一步必须人工审核。

共享规范位于 [base.md](../resources/smart-library/question-bank/prompts/base.md)，首批分难度规范为 [simple.md](../resources/smart-library/question-bank/prompts/simple.md)、[medium.md](../resources/smart-library/question-bank/prompts/medium.md)、[hard.md](../resources/smart-library/question-bank/prompts/hard.md)。后续用户明确新增的出题要求应补充到 base.md 的“用户新增要求”，更新规范版本并保留每批来源。

## v2增补与去重

按 [expansion-v2.md](../resources/smart-library/question-bank/prompts/expansion-v2.md) 增补简单100、中等50、困难50题。每个全书十分位简单10题、中等5题、困难5题，主事件推荐位置错开，并与原有45题及同批其他难度比较。每道新增题记录具体知识点标识、答案要点、模型与规范版本。

本批200题共900条精确原文证据，现已作为唯一常驻题集。保留原编号 S011–S110、M011–M060、H011–H060 和目录ID，确保已有人工修改与审核记录不被重置。旧题编号不再显示；单一批次不显示无效的“首批题目”筛选。

困难题使用至少3个不同物理章的实质证据，首尾跨度至少20章，且存在至少8章的阶段间隔；另写明为什么必须联查这些阶段。章节跨度是筛选条件，不能代替对证据必要性、问题难度的人工判断。不能用无关早期情节来凑跨度。

去重分为出题前分配与作者语义比较、出题后程序筛选两层。程序检查规范化题干完全相同、知识点标识重复、题干字符三元组相似、答案/要点包含度、原文证据区间重合。完全重复和相同知识点必须修正；其余相似对需要比较所问目标及必要答案要点，不因共用人物或原文就直接删除。换个问法问同一知识点仍然算重复。自动检查不能保证没有所有语义重复，最终保留人工审核。

`check-drafts.py` 只读检查草稿；`screen-drafts.py` 生成缓存中的相似对清单。原首批与v2合并脚本为一次性历史工具，常驻化后拒绝重跑覆盖资源或恢复旧题。后续新增须使用新批次、唯一编号并经过审核。

`dedup-review-v2.json` 保存程序筛查结果，`semantic-review-v2.json` 保存作者复查发现及修订依据。这些记录不代表用户已审核通过，也不会授予评测资格。

v2准备脚本仅用于这一次增补，合并后会拒绝再次覆盖编号和基线。后续新批次必须使用新的批次标识与编号范围，并把已审核编辑也纳入去重对照。

## 存储与运行

现题库资源：`resources/smart-library/question-bank/candidates.json`。v2草稿仅用于继续修订；旧首批草稿已清理，历史去重与复查记录保留用于追溯。全书与抽样原文在 `.cache` 中，不进入前端包。

审核记录存于应用数据的 `modules/smart-library/question-bank/<图书SHA256>.json`。读写在独立工作线程中按顺序执行，保存失败时不更新客户端状态；使用 revision 拒绝过期操作。新批次不会因重复题号自动继承旧批次的审核状态。界面与工作线程按需加载，客户端启动不读取整本书或候选证据。

评测详情的“召回原文”只对当前题的证据坐标交集加下划线，避免把其他章节里的相同词句误标为命中；部分覆盖也会划线，完整命中仍按原有评分规则计算。
