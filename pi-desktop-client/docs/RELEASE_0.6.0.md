# Pi Desktop v0.6.0 · Windows 预发布

将 Agent 工作区、智慧面试和知识工坊整合到同一个桌面客户端。本次提供 Windows x64 安装版与便携版，适合体验和反馈。

## 主要能力

- 多项目侧栏：工作会话按项目归组，项目顺序固定，空项目持久保存；纯聊天独立展示。
- Pi 原生会话切换：恢复已有会话时保留进程，跨项目同步工作目录；点击项目名称只展开列表。
- 文件编辑、Git 差异审查、集成终端、内置浏览器及中文本地 HTML 预览。
- 统一主题、悬浮提示和紧凑的会话过程展示；修复模块切换时导航图标位移。
- 岗位与面试管理、问答题库、Monaco 算法编辑与内置 Python 判题。
- 知识资料导入、批量生成候选题目、人工审核与发布。
- 浏览器布局同步改为事件驱动，静止时不再逐帧查询；减少安装包中的重复开发资源。

## 下载与使用

- `Pi-Desktop-Setup-0.6.0-x64.exe`：安装版，可选择目录。
- `Pi-Desktop-0.6.0-x64.exe`：便携启动版；用户数据仍按应用默认位置保存。
- `SHA256SUMS.txt`：安装包与便携版的 SHA-256 校验值。

自带 Pi 运行时和 Python，无需另外安装 Node.js。启动后在“设置 → 模型与 Agent”配置自己的模型账号；安装包不包含开发者凭据和会话。

## 已知限制

- 预发布版本，升级前建议备份所需的本地数据。
- Windows 构建尚未代码签名，系统可能显示未知发布者。
- 不提供自动更新；后续版本需手动下载安装。
- 语音输入未实现；内置浏览器暂无多标签、下载管理和持久登录。
- 修改卡片只追踪当前项目目录内的文件变化，跳过依赖与构建输出等目录。
- 跨项目恢复已有会话不重启 Pi；另一个空项目首次创建工作会话仍需初始化运行环境。
- Monaco 补全尚未接入语言服务器或 AI 补全。模型质量、可用性与费用由所配置的提供商决定。

界面预览与源码启动步骤见仓库 README。此版本尚不代表所有业务流程已在全新 Windows 环境完成端到端验收。
